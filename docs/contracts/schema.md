# WikiMind schema contract (v1)

Status: frozen for lanes L0-L5 in Stage 1. The migration files under
`migrations/` are the executable form of this document. If this document and
`DECISIONS.md` disagree, `DECISIONS.md` wins; report the conflict instead of
changing a decision.

## Scope and conventions

- Postgres 14+ with the `vector` extension (pgvector). The reference embedding
  model is bge-small, hence `vector(384)`.
- Every table except `projects` and `schema_migrations` carries
  `project_id NOT NULL`. Every query in every lane must scope by `project_id`.
- Primary keys are UUIDs unless a table's contract says otherwise. Content
  addresses use lowercase SHA-256 hex strings.
- Enum-like columns use `CHECK` constraints, not Postgres enum types. This is
  the one style used throughout the schema.
- Foreign keys are explicit and have explicit delete behavior. The database is
  the backstop; `wikimind db check` also verifies orphan-sensitive tables.
- Timestamps are `TIMESTAMPTZ` and default to `now()` where present.
- `migrations/NNN_name.sql` files are applied in filename order. Each file
  plus its `schema_migrations` row commits in one transaction. The runner
  records `sha256` of the file bytes and exits 2 if an applied file's hash
  changes.

## Table catalog

### `projects`

Purpose: tenant/project boundary. One of only two tables without `project_id`
(the other is `schema_migrations`).

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | generated by `gen_random_uuid()` |
| `name` | TEXT NOT NULL | display name |
| `created_at` | TIMESTAMPTZ NOT NULL | default `now()` |

### `schema_migrations`

Purpose: migration ledger. Created by the runner, not by a migration file.
Not a project-scoped table.

| Column | Type | Notes |
| --- | --- | --- |
| `name` | TEXT PK | migration filename |
| `sha256` | TEXT NOT NULL | SHA-256 of the file bytes |
| `applied_at` | TIMESTAMPTZ NOT NULL | default `now()` |

### `documents`

Purpose: one ingested source and its L1 memoization key. Raw content is not
stored here; channel text lives in `channels`.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `sha256` | TEXT NOT NULL | source content hash |
| `source_uri` | TEXT NOT NULL | origin locator |
| `parser` | TEXT NOT NULL | parser identity |
| `prompt_version` | TEXT NOT NULL | distillation prompt identity |
| `model` | TEXT NOT NULL | distillation model identity |
| `schema_version` | TEXT NOT NULL | project schema identity |
| `ingested_at` | TIMESTAMPTZ NOT NULL | default `now()` |

Keys:

- `UNIQUE (project_id, sha256, parser, prompt_version, model, schema_version)`
  is the **L1 memoization key** (D2). It answers "may I reuse the citation
  node produced for this exact input?" Changing any component invalidates the
  memoized level-1 result.

### `channels`

Purpose: the quarantined raw layer. Full source text lives only here and
enters a prompt only through Lane 1's tagged, untrusted helper. Claims may
store a short `anchor_quote` excerpt for citation, never the full source body.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | TEXT PK | `sha256(kind || U+001F || normalized_text)` |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `document_id` | UUID NOT NULL FK `documents(id)` ON DELETE CASCADE | |
| `kind` | TEXT NOT NULL | e.g. `paragraph`, `table`, `heading` |
| `ordinal` | INTEGER NOT NULL | non-negative position in the document |
| `raw_text` | TEXT NOT NULL | immutable source text |

Keys and indexes:

- `id` is the primary key; `document_id` and `project_id` are indexed.
- `channel_id(kind, normalized_text)` from `wikimind.db.ids` computes the ID
  with ASCII unit separator `0x1f`. The separator is part of the contract.

### `nodes`

Purpose: graph page identity. Node identity is `(project_id, slug)`, never the
mutable version or rendered prose.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | never reused |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `slug` | TEXT NOT NULL | stable page slug |
| `node_type` | TEXT NOT NULL CHECK | `citation`, `entity`, `concept`, `synthetic`, `memory` |
| `status` | TEXT NOT NULL CHECK | `active`, `stale`, `superseded`, `archived`, `retracted` |
| `current_version_id` | UUID NULL FK `node_versions(id)` | set after the first version |
| `created_at` | TIMESTAMPTZ NOT NULL | default `now()` |

Keys: `UNIQUE (project_id, slug)`. Renames and merges must add a row to
`node_redirects`; an ID or slug is never recycled for a different entity.

### `node_versions`

Purpose: immutable rendered page history. The ledger is the truth; the
rendered text is a projection that can be regenerated.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `node_id` | UUID NOT NULL FK `nodes(id)` ON DELETE CASCADE | |
| `version` | INTEGER NOT NULL CHECK `> 0` | |
| `rendered_text` | TEXT NOT NULL | |
| `fts` | TSVECTOR generated | `to_tsvector('english', rendered_text)` STORED |
| `created_by_job` | UUID NULL FK `jobs(id)` | |

Keys/indexes: `UNIQUE (node_id, version)`, GIN index on `fts`. Immutable
after insert by convention; no update path is provided.

### `node_redirects`

Purpose: old slug to current node mapping after a rename or merge.

| Column | Type | Notes |
| --- | --- | --- |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `from_slug` | TEXT NOT NULL | retired slug |
| `node_id` | UUID NOT NULL FK `nodes(id)` ON DELETE CASCADE | current node |

Primary key: `(project_id, from_slug)`.

### `claims`

Purpose: an atomic, anchored assertion extracted from a channel. Claims are
the units cited by L2 ledger blocks.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `citation_node_id` | UUID NOT NULL FK `nodes(id)` ON DELETE CASCADE | L1 citation node |
| `channel_id` | TEXT NOT NULL FK `channels(id)` ON DELETE CASCADE | passage |
| `anchor_quote` | TEXT NOT NULL | exact supported text |
| `anchor_span` | JSONB NOT NULL | span coordinates/offsets |
| `text` | TEXT NOT NULL | distilled claim |
| `created_by_job` | UUID NULL FK `jobs(id)` | |

### `ledger_blocks`

Purpose: ordered claim ledger for an L2 node. A block is either a claim
reference or an explicitly marked derived assertion.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `node_id` | UUID NOT NULL FK `nodes(id)` ON DELETE CASCADE | page |
| `claim_id` | UUID NULL FK `claims(id)` ON DELETE CASCADE | null only for `derived` |
| `position` | INTEGER NOT NULL CHECK `>= 0` | render order |
| `block_type` | TEXT NOT NULL CHECK | `claim` or `derived` |

Keys:

- `UNIQUE (node_id, claim_id)`.
- The check constraint enforces `claim` blocks have a `claim_id` and `derived`
  blocks do not.

### `edges`

Purpose: typed, provenance-bearing graph relationship.

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID PK | |
| `project_id` | UUID NOT NULL FK `projects(id)` | |
| `src_node` | UUID NOT NULL FK `nodes(id)` ON DELETE CASCADE | |
| `dst_node` | UUID NOT NULL FK `nodes(id)` ON DELETE CASCADE | |
| `edge_type` | TEXT NOT NULL CHECK | see domain below |
| `created_by_job` | UUID NULL FK `jobs(id)` | |

Edge type domain: `relates_to`, `part_of`, `supports`, `contradicts`,
`supersedes`, `cites`, `authored_by`, `uses`, `measured_by`.
Keys: `UNIQUE (project_id, src_node, dst_node, edge_type)`.
Provenance is mandatory in `edge_sources` (D6).

| Column | Type | Notes |

### `node_sources`

| Column | Type | Notes |

## Cross-table rules

1. A citation node (L1) may own claims. Claims must point at a citation node
   and a channel in the same project.
2. A ledger block references a page node and (for `claim` blocks) a claim.
   Removing a claim removes its blocks; removing a page removes its blocks.
3. Edges are unique per `(project, src, dst, type)` and need at least one row
   in `edge_sources`. The database cannot enforce the non-empty provenance
   rule, so `db check` and the compile lane must enforce it.
4. `node_sources` is the page-level provenance graph; `edge_sources` is the
   edge-level graph. Neither is stored as JSONB (D6).
5. Removing a document cascades to its channels and through to claims; the
   compile lane must still explicitly drop/re-render the ledger blocks that
   cited those claims and emit the removal event.
6. No node ID or slug is reused. A rename writes `node_redirects`.
7. Raw text must not appear in `node_versions.rendered_text` or any other
   distilled field.

## Invariant checks and exit codes

`wikimind db check` verifies:

- every expected table exists and `project_id` is `NOT NULL`;
- migration files and recorded SHA-256 hashes agree;
- `claims`, `ledger_blocks`, and `node_versions` have no orphans or
  cross-project references;
- every edge has at least one `edge_sources` provenance row;
- every enum-like column only contains its documented domain;
- `embeddings.vec` is `vector(384)` and sampled rows have 384 dimensions.

Exit codes: `0` clean, `1` warnings only, `2` one or more errors. A missing
connection or an unmigrated database is an error (2).
