question: What is the difference between the RAG-Token and RAG-Sequence models in how they use retrieved documents?
answer:   The RAG-Sequence and RAG-Token models differ in how they utilize retrieved documents during generation. The RAG-Sequence model treats the retrieved document as a single latent variable that is marginalized to calculate the sequence-to-sequence probability, meaning it uses the same document to predict each target token [c-7ad7eab98b64, c-7f1fd271fc92]. In contrast, the RAG-Token model draws a different latent document for each target token, which allows it to generate responses that combine content from several documents [c-0637c340355b, c-54bbcfb98746].
